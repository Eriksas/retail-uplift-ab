# 零售短信营销：A/B 实验分析与增益模型

> 营销短信应该发给谁？
> 不是预测“谁会购买”，而是估计“发短信能让谁的购买概率提高最多”。

本项目用 X5 零售（俄罗斯连锁零售商，2019 年）的短信营销实验数据，把**A/B 测试、数据挖掘和因果推断**串成一个完整流程：先验证随机化、估计平均效应并用 CUPED 降低方差；再用 SQL 从 4,500 多万条交易流水中构造客户特征；最后手写增益模型，找出“发了才会买”的客户，并在假设的成本和毛利下给出投放建议。

README 只记录已经实际完成并验证过的内容，所有数字都来自 `results/` 目录中的代码运行输出。

## 数据
X5 RetailHero Uplift Modeling 比赛数据：200,039 个带实验标签的客户（是否收到短信、之后是否购买）、400,162 个客户的基本信息、45,786,568 行营销前的交易流水。处理变量是“是否收到短信”。来源、校验值和已知问题见 [data/README.md](data/README.md)。

## 主要结果

### 1. A/B 实验分析（`results/stage1_*`）
- **随机化检验通过**：实验组 99,981 人、对照组 100,058 人，样本比例检验 p = 0.863；14 个客户信息和实验前消费变量的 |SMD| 最大为 0.0085，联合检验 p = 0.190。
- **平均效应**：购买率从 60.33% 提高到 63.65%，ATE = 3.32 个百分点，95% 置信区间 [2.90, 3.75]。
- **CUPED**：用实验前交易次数调整，方差减少 12.7%；用 7 个实验前指标做回归调整，相当于样本量放大 1.21 倍，最小可检测效应从 0.61 个百分点降到 0.55 个百分点。
- **坏控制变量**：客户表的“首次兑换积分日期”有一部分发生在短信之后，“截止日后才首次兑换”的比例实验组比对照组高 0.39 个百分点（p = 0.006），说明它受短信影响，不能作为协变量或特征。

### 2. 特征工程（`results/stage2_*`）
- 用 DuckDB 写 SQL，从交易流水中为每个客户构造了 8 组、43 个特征（RFM、近期趋势、积分与促销、购物篮、门店忠诚度、购物时间、客户信息）。全部只用 2019-03-19 之前的信息。
- **泄露检查**：43 个特征在实验组和对照组之间的 |SMD| 最大为 0.0094。
- 训练集、验证集、测试集按 60% / 20% / 20% 分层划分（120,023 / 40,008 / 40,008 人）。

### 3. 增益模型（`results/stage3_*`）
手写了 S-learner、T-learner、X-learner 和类别转换法。其中 S-learner、T-learner、类别转换法与 scikit-uplift 的预测完全一致；X-learner 用已知真实增益的模拟数据做了验证。12 个候选模型在验证集上比较，测试集只评估一次：

| 模型 | 验证集 Qini 系数 | 测试集 Qini 系数 | 测试集前 30% 增益 |
|---|---|---|---|
| **T-learner（逻辑回归，最终选择）** | 0.0155 | 0.0129 | 6.57 个百分点 |
| X-learner（逻辑回归 + Ridge） | 0.0147 | 0.0121 | 5.99 个百分点 |
| S-learner（LightGBM） | 0.0147 | 0.0109 | 6.39 个百分点 |
| T-learner（LightGBM） | 0.0102 | 0.0048 | 4.44 个百分点 |
| 普通响应模型（LightGBM，对照） | −0.0112 | −0.0052 | 1.47 个百分点 |

### 4. 评估与不确定性（`results/stage4_*`，测试集）
- 最终模型的 Qini 系数 95% bootstrap 置信区间为 [0.0068, 0.0195]；置换检验中 500 次随机打乱没有一次达到它的水平（p < 0.002）。
- 只发给预测增益最高的 30% 的客户，就能拿到全部增量购买的 59.3%；普通响应模型的前 30% 只能拿到 13.3%，比随机还差。
- 最终模型和第二名（X-learner）的差异不显著（Qini 系数之差的 95% 区间为 [−0.0011, 0.0026]）。
- 模型预测增益最低的 10% 客户，实际增益为 +3.24 个百分点，**没有证据表明存在“越发越不买”的客户**。

### 5. 业务落地（`results/stage5_*`）
- 同样发给 30% 的客户，增益模型每 1 万人预计多带来约 197 次购买，普通响应模型约 44 次。
- **ROI 模拟（参数为假设：短信成本 2、毛利率 25%）**：发给预测增益最高的约 50% 的客户利润最高，比全部发送多赚约 16%。敏感性分析显示，短信越便宜、毛利越高，最优发送比例越接近全部发送；短信越贵、毛利越低，越应该只发给一小部分人。
- **四类人群（测试集验证）**：“可说服的人”（占 31.2%）不发短信时只有 41.0% 会买，短信实际增量 6.02 个百分点；“铁定买”（占 31.2%）不发也有 83.4% 会买，增量只有 1.56 个百分点。
- **一条可解释的规则**：用过较多活动积分、但购物天数不多的客户，测试集上的实际增量为 7.75 个百分点。

## 局限
- 实验对象都是截止日前 23 天内买过东西的活跃客户，结论不能直接推广到沉睡客户。
- 官方没有说明短信内容和购买的统计期；随机化是通过检验验证的，而不是官方声明的。
- 没有商品目录表，做不了品类偏好特征。
- 增益信号较弱（平均 3.32 个百分点），按预测增益分组后组内噪声较大；排名前几的模型之间没有显著差异。
- 人群画像和规则只说明“哪些特征和效应大小有关”，不是这些特征的因果作用。

## 目录结构
```
data/          原始与处理后数据（不进 Git，来源见 data/README.md）
notebooks/     01_ab_test → 02_features → 03_uplift_models → 04_evaluation → 05_targeting

LEARNING_LOG.md  学习日志：每一步的原理、结果、踩坑记录和问答
```

## 复现
```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```
1. 从 [data/README.md](data/README.md) 列出的镜像下载 3 个文件，放到 `data/raw/x5/`（`src/data.py` 会校验 SHA256，并把交易流水转存为 Parquet）。
2. 按顺序执行 `notebooks/01` 到 `05`，例如：`.venv\Scripts\jupyter-nbconvert.exe --to notebook --execute --inplace notebooks/01_ab_test.ipynb`。

随机种子统一为 `42`（见 `src/config.py`）。
