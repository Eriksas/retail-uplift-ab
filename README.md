# 零售短信营销：A/B 实验分析与增益模型

> 营销短信应该发给谁？
> 不是预测“谁会购买”，而是估计“发短信能让谁的购买概率提高最多”。

**项目状态：进行中。** 本 README 只记录已经实际完成并验证过的内容，所有结果数字都来自 `results/` 目录中的代码运行输出。

## 项目内容
1. **A/B 实验分析**：验证分组是否随机（样本比例失衡检验、平衡性检验），估计短信的平均效应并做显著性检验，用 CUPED（借助实验前的消费数据降低方差）提高检验精度。
2. **数据挖掘**：用 SQL（DuckDB）从 4,500 多万条交易流水中构造客户特征。
3. **因果推断 / 增益模型**：手写 S-learner、T-learner、X-learner，用增益曲线和 Qini 曲线评估，最后在预算约束下决定发给谁。

## 数据
X5 RetailHero Uplift Modeling 比赛数据（俄罗斯连锁零售 X5，2019 年）：带实验标签的客户、客户信息，以及营销前的交易流水。处理变量是“是否收到短信”。来源和说明见 [data/README.md](data/README.md)。
