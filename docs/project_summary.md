# 项目总结：零售短信营销的 A/B 分析与增益模型

> 所有数字都来自 `results/` 目录中的代码输出。ROI 模拟中的短信成本、毛利率是假设。

## 一句话
用 X5 零售的短信营销随机实验数据，先做 A/B 分析，再从 4,500 多万条交易流水中挖掘客户特征，最后用增益模型找出“发了才会买”的客户，并给出预算约束下的投放建议。

## 简历写法（可按篇幅取舍）
**零售短信营销增益模型（X5 RetailHero 数据，个人项目）**
- **A/B 实验分析**：通过样本比例检验、14 个变量的平衡性检验和联合检验验证随机化，估计短信的平均效应为 +3.32 个百分点（95% 置信区间 [2.90, 3.75]）；用 CUPED 降低方差 12.7%，最小可检测效应从 0.61 降到 0.55 个百分点；识别出一个受处理影响的坏控制变量。
- **特征工程**：用 DuckDB SQL 从 4,580 万行交易流水中构造 43 个客户特征（RFM、积分促销、门店忠诚度、购物时间等），设置截止时间并用平衡性检验确认无信息泄露。
- **增益模型**：手写 S/T/X-learner 与类别转换法（与 scikit-uplift 逐点一致，X-learner 用模拟数据验证），在 12 个候选中按验证集选出逻辑回归 T-learner；测试集上，预测增益最高的 30% 客户贡献了 59.3% 的增量购买，而普通响应模型只有 13.3%；bootstrap 与置换检验确认显著优于随机。
- **业务落地**：在假设的成本与毛利下，只发给约一半客户可比全部发送多赚约 16%；用测试集验证“可说服的人”的实际增量为 6.02 个百分点，“铁定买”的人只有 1.56 个百分点。

## 1 分钟版本
这个项目回答“短信该发给谁”。我先把它当 A/B 实验来分析：验证随机化后，估计出短信让购买率平均提高 3.32 个百分点，又用 CUPED 把方差降低了 12.7%。然后用 SQL 从 4,500 万条交易流水里构造了 43 个客户特征，并确认没有信息泄露。接着手写了几种增益模型，在验证集上选出 T-learner；测试集上，它挑出的前 30% 客户贡献了近六成增量，而普通的“谁会买”模型只贡献一成多，比随机还差。最后我在假设的成本下算出最优发送比例，并用测试集验证了“可说服的人”和“铁定买”这两类人群的真实增量。

## 3 分钟版本（按流程讲）
1. **业务问题**：短信有成本，发给本来就会买的人是浪费。所以要估计的不是“谁会买”，而是“发了能多买多少”，也就是条件平均处理效应。
2. **A/B 分析**：官方没说短信是否随机发送，所以我先做了样本比例检验、14 个变量的平衡性检验和联合检验，还把实验前的消费当作安慰剂检验，都通过了。平均效应是 3.32 个百分点。用实验前交易次数做 CUPED，方差减少 12.7%；7 个实验前指标做回归调整，相当于样本量放大 1.21 倍。
3. **坏控制变量**：客户表的首次兑换积分日期有一部分在短信之后，而且实验组比对照组更多，说明它受短信影响，特征工程时要截断。
4. **特征工程**：交易流水每一行是一件商品，要先按交易去重再按客户汇总。我用 DuckDB 直接在 Parquet 上写 SQL，构造了 43 个特征，并用平衡性检验做泄露检查。
5. **异质性初探**：交易频繁、刚买过的人增量只有约 2 个百分点；交易少、客单价低、新办卡、年龄大的人增量有 4 到 6 个百分点。
6. **增益模型**：手写 S/T/X-learner 和类别转换法，和 scikit-uplift 对过，X-learner 用模拟数据验证。逻辑回归版的 T-learner 在验证集上最好；LightGBM 反而过拟合，因为增益信号很弱。
7. **评估**：手写增益曲线和 Qini 系数；最终模型的 Qini 系数置信区间不含 0，置换检验 p < 0.002。普通响应模型的 Qini 是负的，因为它挑中的都是本来就会买的人。另外，模型预测为负增益的人，实际增益是正的，所以没有证据表明存在勿扰型客户。
8. **业务落地**：按预测增益排序发，同样 30% 的预算，增量是响应模型的 4 倍以上。在假设参数下，发给一半客户利润最高；敏感性分析显示，最优比例取决于短信成本和毛利的比例。

## 局限与下一步
- **适用范围**：实验对象都是近期活跃客户，推广到沉睡客户要另做实验。
- **信息缺失**：没有短信内容、购买统计期和商品目录，限制了特征和业务解读。
- **信号弱**：平均增量只有 3.32 个百分点，模型之间差异不显著，分组后的实际增益噪声较大。
- **可以改进的方向**：
  - 用更多随机实验数据，或在线上保留随机对照组持续收集，提高增益估计的精度；
  - 尝试对增益直接建模的方法（如因果森林），并用 bootstrap 检验是否显著优于 T-learner；
  - 把 ROI 模拟中的“增量购买金额”从客单价中位数换成真实的增量消费额（需要订单金额作为结果变量）。
